# Data Mining Lab Manual

## Learning Objectives

By the end of this lab course, students should be able to:

- Understand the complete **data mining workflow**.
- Perform **data preprocessing** and **exploratory analysis**.
- Apply **classification, clustering, association rule mining, and anomaly detection** algorithms.
- Evaluate models using standard **performance metrics**.
- Build a complete **end-to-end data mining project**.

## Software Requirements

- **Python:** 3.x
- **Environment:** Jupyter Notebook / Google Colab
- **Libraries:** `pandas`, `numpy`, `matplotlib`, `scikit-learn`, `mlxtend`

---

## Lab Schedule

### Lab 1: Introduction to Python for Data Mining

- Python basics
- Variables, data types, operators
- Lists, tuples, dictionaries
- Functions and loops
- Reading and writing CSV files using `pandas`

### Lab 2: Data Preprocessing and Exploration

- Loading datasets
- Handling missing values
- Removing duplicates
- Encoding categorical variables
- Feature scaling (**Normalization** and **Standardization**)
- Descriptive statistics

### Lab 3: Data Visualization and Exploratory Data Analysis (EDA)

- Histograms
- Bar charts
- Scatter plots
- Box plots
- Correlation matrix and heatmap
- Identifying outliers and relationships

### Lab 4: Frequent Pattern Mining – Apriori Algorithm

- Association rules
- **Support**
- **Confidence**
- **Lift**
- Apriori implementation using `mlxtend`

### Lab 5: Frequent Pattern Mining – FP-Growth

- FP-tree construction
- FP-Growth algorithm
- Mining frequent itemsets
- Comparison between **Apriori** and **FP-Growth**

### Lab 6: Classification – Decision Trees

- Decision tree concepts
- **Entropy** and **Gini index**
- Training a decision tree classifier
- Tree visualization
- Accuracy evaluation

### Lab 7: Classification – Naive Bayes

- Bayes theorem
- Gaussian Naive Bayes
- Multinomial Naive Bayes
- Classification of text or tabular data
- Performance evaluation

### Lab 8: Classification – Support Vector Machines (SVM)

- Linear and nonlinear SVM
- Kernel functions
- Model training
- Hyperparameter tuning
- **Accuracy, precision, recall, and F1-score**

### Lab 9: Clustering – K-Means

- Distance measures
- K-Means algorithm
- Choosing the number of clusters (**Elbow method**)
- Cluster visualization
- Interpretation of clusters

### Lab 10: Clustering – Hierarchical Clustering and DBSCAN

- Agglomerative clustering
- Dendrogram analysis
- DBSCAN algorithm
- Density-based clustering
- Comparison with **K-Means**

### Lab 11: Outlier Detection and Ensemble Methods

- Z-score method
- IQR method
- Isolation Forest
- Random Forest classifier
- Feature importance analysis

### Lab 12: Mini Project – End-to-End Data Mining Pipeline

Students should:

1. Select a real dataset.
2. Perform preprocessing.
3. Conduct exploratory analysis.
4. Apply at least one classification algorithm.
5. Apply at least one clustering or association rule mining algorithm.
6. Evaluate the results.
7. Present findings in a short report and presentation.
